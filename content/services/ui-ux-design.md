Design here is not a hand-off over a wall. We design the screens, flows and visual system with the same team that will implement them in Flutter, so what you approve is what ships.

That means platform conventions (iOS vs Android), accessibility, empty states, and the awkward mid-flow errors — not only the happy-path mockup.

## What you get

- UX flows for the product you are actually building
- UI that can be implemented in Flutter without a redesign round
- A visual language your next screens can extend
- Collaboration with your product owner, not a siloed design phase

If you already have a design system or a Figma file, we work from that. If you do not, we start with the user jobs and build only what the app needs.
